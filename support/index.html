Best way to report a bug

Use Pro Bug Report Mode to generate a shareable support bundle.

  1. Open the Session
  2. Run Bug Report export
  3. Say “mark” at important moments
  4. Share the generated report
If speech recognition isn’t available, the export can still complete and include a note explaining why.

Troubleshooting

I don’t see the speech permission prompt

If you’ve already answered the prompt before, iOS won’t show it again. Check Settings → Privacy & Security → Speech Recognition.

Bug Report export fails on iPad

Some iPads can return speech errors. In those cases the report still exports with a transcript-failure note so you can still share the video and markers.

How do I record another app?

Start Broadcast Recording, choose Screen Flow Pro, then switch to the other app. Stop from the system UI.

How do I restore purchases?

Open the Upgrade screen and tap Restore Purchases. Make sure you’re signed into the same Apple ID that purchased Pro.
