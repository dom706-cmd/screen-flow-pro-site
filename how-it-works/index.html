How it works

A quick overview you can link to from your App Store description, onboarding, or support replies.

1. Record

Start a Broadcast recording

Tap Start Broadcast Recording, choose Screen Flow Pro, and record your screen in any app. Stop from Control Center or the red status pill.

  • Works across apps (ReplayKit broadcast)
  • Saves a movie file to shared App Group storage
2. Session

Recordings become Sessions

Back in Screen Flow Pro, refresh your Library. Your new Session appears, ready to edit and export.

  • Title + mode
  • Timeline markers
  • Keywords (Pro)
3. Edit

Scrub + mark moments

Pinned preview stays visible while you scrub and add markers. Markers make it easy to jump to exact moments.

4. Export

Share what you captured

Export a raw MOV in Free. Pro unlocks full-quality presets and Bug Report Mode bundles optimized for sharing in Messages.

If speech recognition fails, Bug Report export can still complete and include a helpful note — so you never lose the report.
