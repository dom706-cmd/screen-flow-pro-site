The 30‑second bug report checklist

  • Show the setup — 3–5 seconds before the bug.
  • Timestamp the moment — say “mark” or add a manual marker.
  • Narrate one sentence — what you expected, what happened.
  • Export a single bundle — easy to share in Messages/email.

How Screen Flow Pro helps

  • Record across apps using the Broadcast picker.
  • Open the Session and scrub the timeline fast.
  • Use Bug Report Mode to generate a timecoded transcript + markers.
  • Share the output with fewer attachments for higher success rates.
Pro tip: if the issue is intermittent, record longer and drop multiple markers. Support can jump right to each occurrence.
